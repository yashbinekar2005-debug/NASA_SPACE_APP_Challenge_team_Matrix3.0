# Data dictionary

Factor values, derivations, units, sources and missing-data conventions.
Codes and formulas here match `js/data/factors.js`,
`tools/lib/features.mjs`, `tools/lib/planetary-probe.mjs` and
`tools/discover.mjs`.

## Factor fields

| Key | Label | Unit | Kind | Range | Cap / scale | Evidence type | Comparability |
|---|---|---|---|---|---|---|---|
| `temp` | Temperature | °C | continuous | −150…60 | 200 °C | measurement | 0.70 |
| `solar` | Solar illumination | kWh/m²/day | continuous | 0…20 | 12 | measurement | 0.60 |
| `ice` | Ice and water | index | index / evidence class | 0…100 | 100 | proxy | 0.50 |
| `soil` | Volcanic soil | index | index | 0…100 | 100 | proxy | 0.70 |
| `terrain` | Terrain roughness | index | index | 0…100 | 100 | proxy | 0.85 |
| `dry` | Dryness | index | index | 0…100 | 100 | proxy | 0.60 |
| `tube` | Lava-tube access | index | capability | 0…100 | 100 | capability | 0.80 |

Direction is always “higher index = stronger evidence / rougher / drier /
more mafic”. Temperature and solar are absolute physical values, not indexes.

## Stored measurement object

Each factor in `v` may be a bare number or an object:

```js
{
  value: 25.62,                 // finite number
  uncertainty: 1.91,            // 1σ in the factor's unit
  unit: '°C',
  source: { id, name, url, period, note },
  measurementType: 'annual_mean_surface_temperature',
  evidenceClass: 1,             // optional, ice proxy only
  evidenceClassUncertainty: 0.4,
  quantiles: { p10, p50, p90 }  // optional distribution
}
```

`null` or an omitted key means **not available**. It is not zero.

## Earth factors

Earth candidates come from the committed snapshot in
`js/data/discovered.js`, generated by `tools/discover.mjs`. All site values are
produced by deterministic functions in `tools/lib/features.mjs`.

| Factor | Derivation | Source IDs | Uncertainty |
|---|---|---|---|
| `temp` | Annual mean MERRA-2/POWER Earth skin temperature (`TS`, fallback `T2M`), °C | `nasa-power-ts` | `max(0.8, monthly spread × 0.25)` |
| `solar` | Annual mean all-sky surface shortwave downward irradiance, kWh/m²/day | `nasa-power-solar` | `max(0.2, monthly spread × 0.25)` |
| `dry` | `100 × [0.7 × (1 − min(1, P_annual/1000 mm)) + 0.3 × (1 − RH/100)]` | `nasa-power-dryness` | 6 index points |
| `ice` | Evidence class from snow depth, frost days and root-zone wetness; index `100 × [0.55·min(1, snow/30 cm) + 0.25·min(1, frost/200 d) + 0.20·min(1, wetness/0.4)]` | `nasa-power-water` | 8 index points, class σ 0.4 |
| `soil` | `0.7 × Macrostrat lithology score + 0.3 × SoilGrids sand fraction`, or whichever component exists | `soilgrids+macrostrat` | 14–28 index points depending on components |
| `terrain` | `100 × min(1, local relief / 1000 m)`, relief = max − min of a 3×3 SRTM 90 m sample | `opentopodata-srtm90m` | 10 index points |
| `tube` | `max(OSM cave-entrance score, 0.5 × geology capability)`; OSM score `100 × (1 − exp(−N/2))` for N entrances within 25 km | `osm+macrostrat-caves` | 25 index points |

### Ice evidence classes (Earth)

| Class | Meaning |
|---|---|
| 0 | No surface water/ice evidence in the selected datasets |
| 1 | Moist ground or seasonal water present |
| 2 | Seasonal snow or frequent frost |
| 3 | Persistent snow, ice or permafrost signature |

Class thresholds: 3 if snow ≥ 10 cm or frost ≥ 180 d/yr; 2 if snow ≥ 1 cm or
frost ≥ 60 d/yr; 1 if root-zone wetness ≥ 0.25 or precipitation ≥ 1 mm/day.

### Macrostrat lithology scores

| Match | Score |
|---|---|
| basalt / mafic / flood basalt | 95 |
| volcanic / andesite / rhyolite / dacite / tuff / ignimbrite / pyroclastic | 82 |
| gabbro / dolerite / diabase / intrusive / granite / igneous | 65 |
| carbonate / limestone / dolomite / karst / marble | 45 |
| unconsolidated / alluvium / gravel / sand / till / glacial | 35 |
| sandstone / shale / mudstone / siltstone / conglomerate | 30 |

The highest matching score is used. `karst` is tracked separately for the tube
capability proxy.

## Moon point-probe factors

`GET /api/probe?body=moon&lat=…&lon=…`

| Factor | Product | Derivation | Completeness |
|---|---|---|---|
| `temp` | LRO Diviner annual-average hourly maps (`temp_avg_hour`, layer 3) | Mean of 8 local-hour samples (0, 3, 6, 9, 12, 15, 18, 21 h), converted K → °C; at least 3 samples required | `n/8 local-hour samples` |
| `solar` | NASA Moon Fact Sheet solar constant (1361 W/m²) | `10.398 × max(0, cos(lat))` kWh/m²/day; geometric annual mean for a level surface | `geometric estimate` |
| `dry` | NASA Moon Fact Sheet | Vacuum reference, index 100 | `reference value` |
| `soil` | Kaguya MI FeO weight percent (±50° only) | `100 × min(1, FeO_wt% / 20)`; valid FeO 0–40 wt% | `single mapped pixel` |
| `terrain` | LRO LOLA DEM 256 ppd v06 | `100 × min(1, (max − min) / 1000 m)` over a 3×3 grid at ±0.18° (≈11 km across); at least 5 points | `n/9 DEM samples` |
| `ice` | — | Not calculated: no global lunar volatile point product is connected. Always `null`, never inferred from latitude | `not queried…` |
| `tube` | — | Not calculated for an arbitrary point | not present |

Moon temperature uncertainty is a fixed **5 K allowance** covering the numerical
integration of the diurnal curve with eight samples (the 8-sample mean differs
from a 24-hour integral by about 2.5 K at the equator) plus mapped-product
representativeness. It is **not** a published instrument error. The real
diurnal spread is stored separately as `diurnalSpread`, with `minC` / `maxC`.

Lunar solar is a geometry estimate: local horizon, slopes and permanent shadow
are not modelled, and the UI says so.

## Mars point-probe factors

`GET /api/probe?body=mars&lat=…&lon=…`

| Factor | Product | Derivation | Completeness |
|---|---|---|---|
| `temp` | Mars Climate Database v6.2 | Mean of 25 seasonal surface temperatures, K → °C | `n/25 seasonal samples` |
| `solar` | Mars Climate Database v6.2 | Mean downward surface shortwave W/m² × 24 / 1000 | `n/25 seasonal samples` |
| `pressureKpa` | Mars Climate Database v6.2 | Mean surface pressure Pa / 1000 (reported as metadata, not a scored factor) | `n/25 seasonal samples` |
| `ice` | MCD surface H₂O layer | `100 × min(1, mean_kg/m² / 6)` with evidence class | `25 seasonal samples` |
| `dry` | MCD water-vapour column | `100 × (1 − min(1, column / 0.2 kg/m²))` | `25 seasonal samples` |
| `soil` | USGS SIM3292 global geology | Keyword class of the mapped unit description | `single mapped polygon` |
| `terrain` | NASA MOLA 128/64 ppd merged DEM | Relief index over a 3×3 grid at ±0.12° (≈14 km across) | `n/9 DEM samples` |
| `tube` | — | Not calculated: no global surveyed cave/tube point dataset | not present |

### Mars ice evidence classes

| Class | Threshold (seasonal mean surface H₂O layer) |
|---|---|
| 3 | ≥ 3 kg/m² |
| 2 | ≥ 0.5 kg/m² |
| 1 | ≥ 0.05 kg/m² |
| 0 | < 0.05 kg/m² |

### SIM3292 geology proxy classes

| Unit description match | Score | Label |
|---|---|---|
| volcanic / basalt / mafic / edifice / shield / flow | 92 | volcanic / mafic unit |
| plains | 58 | plains unit |
| transition / highland / Noachian / crater / basin / plateau | 55 | highland or transition unit |
| aqueous / clay / hydrated / sulfate / sedimentary / delta / lacustrine / alluvial / fluvial | 48 | aqueous or sedimentary unit |
| no keyword match | 45 (σ 30) | undifferentiated unit |
| mantle / dust / sand / aeolian / dune | 35 | aeolian / mantle cover |
| polar / ice / frost / cap | 15 | polar ice or frost unit |

The first matching rule wins. This is a geologic-map proxy, not in-situ
mineralogy.

### MCD query and uncertainty

MCD is queried at **0 m above the local surface** (`zkey=3`, `altitude=0`).
The CGI rejects negative “above surface” altitudes, so the MOLA elevation is
reported as metadata rather than passed as an altitude. Values use local time
12 h with diurnal averaging and 25 seasonal samples.

- `temp` uncertainty: `max(2, seasonal spread × 0.35)` — a representativeness
  allowance, not a published model error.
- `solar` uncertainty: `max(0.2, spread × 24 / 1000 × 0.35)`.
- `pressureKpa` uncertainty: `max(0.01, spread / 1000 × 0.35)`.
- Seasonal spread is stored separately as `seasonalSpread`.

MCD is labelled **model climatology**, not a direct surface station
measurement, everywhere it appears.

## Probe payload

```json
{
  "schema": "astra.planetary-probe/1",
  "body": "moon",
  "lat": 0,
  "lon": 0,
  "dataset": "NASA Moon Trek point probe",
  "source": { "id": "astra-moon-point-probe", "name": "…", "url": "…", "period": "…", "resolution": "…", "evidenceType": "…" },
  "sources": [{ "id": "lro-lola-dem-256ppd", "name": "…", "url": "…" }],
  "values": { "temp": { "value": -64.57, "uncertainty": 5, "unit": "°C", "source": { "id": "lro-diviner-hourly" } } },
  "completeness": { "temp": "8/8 local-hour samples", "ice": "not queried…" },
  "warnings": ["…"],
  "presentFeatures": ["temp", "solar", "dry", "soil", "terrain"],
  "retrievedAt": "2026-11-15T00:00:00.000Z"
}
```

`presentFeatures` lists only factors with a finite `value`. `null` factors stay
in `values` and have a completeness explanation.

## Discovery snapshot

`js/data/discovered.js` exports a committed `DISCOVERY` object:

| Field | Meaning |
|---|---|
| `schema` | `astra.discovery/1` |
| `generatedAt` | ISO timestamp of generation |
| `engineVersion` / `configVersion` | Engine and config used |
| `generator` | `tools/discover.mjs` |
| `grid` | step, land cells, screened, with climate, shortlisted, validated |
| `shortlist` | per-target and maximum candidate counts, target IDs |
| `sources` | dataset records with id, name, url, role, auth, period/resolution |
| `candidates` | discovered Earth sites |
| `warnings` | generation-time warnings |

Each candidate carries `id`, `name`, `region`, `lat`, `lon`, `cellDegrees`,
`discovered`, `conf`, `tags`, `v`, `sourceIds` and provenance notes. The name
and region are reverse-geocoder labels only; they never affect the score.

Regenerate and review with:

```bash
node tools/discover.mjs
```

## Missing-data conventions

| Situation | Behaviour |
|---|---|
| Product request fails or times out | factor `null`, warning added |
| Point outside product coverage (e.g. Kaguya FeO beyond ±50°) | factor `null`, warning added |
| Product not connected (lunar ice, arbitrary-point caves) | factor `null`, completeness says so |
| Fewer than 3 lunar temperature hours | temperature `null` |
| Fewer than 5 DEM samples | terrain `null` |
| Factor `null` in scoring | excluded; remaining weights renormalised |
| Coverage below 50 % | status `insufficient_coverage` |
| Fewer than 2 valid weighted factors | status `insufficient_features` |

No latitude-based ice, synthetic temperature or guessed soil value is inserted
anywhere in the probe path.
